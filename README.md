# CCNA Lab 07 - NAT & PAT

##  Project Overview

This lab demonstrates how Network Address Translation (NAT) and Port Address Translation (PAT) allow devices with private IP addresses to communicate with an external network using Cisco Packet Tracer.

---

## Objectives

- Understand the purpose of NAT
- Understand the difference between inside and outside networks
- Configure NAT Overload (PAT)
- Identify inside and outside router interfaces
- Allow multiple private hosts to access an external network
- Verify NAT translations and connectivity
